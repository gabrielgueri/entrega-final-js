# Jokenpô (Pedra, Papel e Tesoura)

Jogo interativo de Pedra, Papel e Tesoura desenvolvido com **HTML**, **CSS** e **JavaScript**, estruturado para atender a todos os degraus de avaliação da disciplina[cite: 1].

## Estrutura do Projeto

Os ficheiros ficam na raiz do repositório[cite: 1]:

- `index.html`: estrutura da página, placar, arena do jogo, campo de meta, botões de jogada e histórico.
- `estilo.css`: estilização visual, layout responsivo e suporte aos temas escuro e claro.
- `script.js`: lógica do jogo, validação de entrada, controle de tema, histórico em array e persistência de recorde.
- `README.md`: documentação do projeto.

## Requisitos Atendidos

- **Mínimo[cite: 1]:** Página inicial nomeada `index.html`, estilos em `estilo.css`, lógica em `script.js`, botão que alterna o tema da página utilizando condicional `if/else` e publicação pronta para GitHub Pages[cite: 1].
- **Intermediário[cite: 1]:** Campo para definir a meta de vitórias com validação contra campo vazio, letras/texto não numérico ou valores inválidos[cite: 1].
- **Completo[cite: 1]:** Armazenamento do histórico de partidas em um `array` percorrido com laço `for` e salvamento do recorde de vitórias no `localStorage`[cite: 1].
- **Apresentação[cite: 1]:** Código organizado e comentado para demonstração ao vivo e explicação de linhas na aula 17[cite: 1].

## Como Publicar no GitHub Pages

1. Crie um repositório público no GitHub e envie `index.html`, `estilo.css`, `script.js` e `README.md` para a raiz.
2. Acesse **Settings** > **Pages** no repositório.
3. Em **Build and deployment**, selecione a branch `main` (pasta `/root`) e salve.
4. Aguarde a publicação e abra o link gerado do GitHub Pages[cite: 1].
